# ♟️ Ajedrez Web — Winter Arc (Proyecto 1)

Aplicación de ajedrez modular desarrollada en JavaScript Vanilla con estándares **WCAG 2.1 AA**, motor de IA con algoritmo **Minimax**, reloj de ajedrez configurable e historial en **Notación Algebraica PGN**.

## 🚀 Tecnologías Utilizadas

- **JavaScript (ES Modules)**: Arquitectura orientada a objetos modular.
- **CSS3 (BEM + Design Tokens)**: Layout con CSS Grid responsive y accesibilidad visual.
- **Vite**: Empaquetador y entorno de desarrollo optimizado.
- **HTML5 & ARIA**: Semántica nativa y patrones A11y (Roving Tabindex, `aria-live`).

## 🛠️ Instalación y Ejecución

```bash
# 1. Clonar el repositorio
git clone [https://github.com/tu-usuario/chess-web-winterarc.git](https://github.com/tu-usuario/chess-web-winterarc.git)

# 2. Entrar al directorio
cd chess-web-winterarc

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
